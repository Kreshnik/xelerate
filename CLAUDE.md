## Design inspiration

Visual and structural inspiration for this rebuild:

- https://laravel.com/forge

Lean on the layout, typography rhythm, content density, and component patterns from these references when designing new sections or refactoring existing ones.

## Default font

The site uses **Instrument Sans** (loaded via `next/font/google`) as the default sans-serif. Apply it via the `--font-sans` CSS variable wired into Tailwind's theme.
